# Catálogo de fotos — Montevideo Flowers

Fotos de producto del catálogo, nombradas por ID (`P001.jpg` … `P139.jpg`),
en correspondencia con `Catalogo Definitivo v1.xlsx` / `.csv`.

Se sirven por CDN vía jsDelivr:

    https://cdn.jsdelivr.net/gh/USUARIO/REPO@main/P001.jpg

Para actualizar una foto: reemplazar el archivo con el mismo nombre y hacer push.
jsDelivr cachea por rama, puede tardar unos minutos en reflejar el cambio
(o usar un tag/commit fijo para forzar la versión).
